# Beijing Person Data

The five person directories are under `data_new/`. They contain files such as `daily_draft.json`, `event_transfer.json`, `event_tree.json`, `location.json`, and `persona.json`.

This directory does not contain `daily_event.json`. To use an evaluation script that requires it, first prepare input in the format described by that method, such as daily activities or geolocation records extracted from a simulation.
